## Цена места

Веб-приложение для анализа коммерческой локации по адресу. Показывает точку на карте OpenStreetMap, оценивает локацию, считает финансовую модель и формирует предварительный бизнес-план.

### Возможности

- **Анализ локации** — трафик, аренда, конкуренты (OSM), кадастр, плотность, парковки
- **Радиус анализа** — 1 / 3 / 5 / 10 км (по умолчанию 3 км)
- **Тип бизнеса** — кафе, магазин, салон, аптека, фитнес, услуги
- **Оценка локации** — сводный балл 0–100
- **Финансовый калькулятор** — выручка, расходы, прибыль, ROI, окупаемость
- **Бизнес-план** — автоматический отчёт с печатью и копированием

### Стек

- HTML + CSS + JavaScript (без фреймворков и сборщиков)
- [Leaflet.js](https://leafletjs.com/) — карта OpenStreetMap
- [Nominatim](https://nominatim.org/) — бесплатный геокодер

### Структура

```
cena-mesta/
├── index.html   # страница приложения
├── style.css    # тёмная адаптивная тема
└── script.js    # карта, геокодер, заглушки аналитики
```

### Как запустить

**Вариант 1 — открыть файл напрямую**

1. Перейдите в папку `cena-mesta/`
2. Откройте `index.html` в браузере (двойной клик или перетаскивание в окно браузера)

> При открытии через `file://` геокодер может не отвечать из‑за ограничений браузера (CORS). Если запросы не проходят — используйте локальный сервер (вариант 2).

**Вариант 2 — локальный HTTP-сервер (рекомендуется)**

```bash
cd cena-mesta
python3 -m http.server 8080
```

Откройте в браузере: [http://localhost:8080](http://localhost:8080)

**Вариант 3 — GitHub Pages**

1. В настройках репозитория: **Settings → Pages**
2. Source: ветка `main`, папка `/cena-mesta`
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`

### Использование

1. Введите адрес, выберите тип бизнеса и радиус анализа
2. Нажмите **Анализировать** — приложение найдёт координаты и поставит метку на карте
3. Под картой появятся метрики локации, оценка и круг радиуса
4. Ниже — финансовый калькулятор (поля заполняются автоматически, можно менять)
5. В конце — предварительный бизнес-план (печать / копирование)
6. Кнопка **Моё местоположение** центрирует карту на ваших GPS-координатах

### Ограничения

- Метрики трафика, аренды, кадастра — оценочные заглушки; конкуренты — из OpenStreetMap (Overpass API)
- Nominatim: не более 1 запроса в секунду (политика использования OSM)
- Для продакшена потребуется собственный бэкенд и реальные источники данных (трафик, аренда, кадастр)
