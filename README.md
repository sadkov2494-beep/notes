# Заметки с Сейфом

Нативное Android-приложение для создания заметок с защищённым разделом «Сейф». Полностью локальное (offline), целевой магазин — RuStore.

## Стек

| Компонент | Технология |
|-----------|------------|
| Язык | Kotlin |
| UI | Jetpack Compose + Material 3 (Material You / Monet) |
| Архитектура | Single Activity, MVVM |
| DI | Hilt |
| Обычные заметки | Room (SQLite) |
| Сейф | Room + SQLCipher |
| Навигация | Compose Navigation (type-safe) |
| Биометрия | BiometricPrompt + AndroidKeyStore |
| Напоминания | WorkManager |
| Архивация | Zip4j (AES-256, `.nbk`) |
| Фото | CameraX, сжатие JPEG 1200px / 85% |

## Возможности

- **Заметки**: Markdown-разметка (жирный, курсив, H1–H3, списки), чек-листы, до 10 фото на заметку, напоминания
- **Группы**: цвет и иконка Material Icons; обычные группы и группы Сейфа разделены
- **Сейф**: шифрование SQLCipher, PBKDF2 из мастер-пароля, биометрия, фраза восстановления, записи паролей, генератор паролей
- **Безопасность**: автоблокировка при сворачивании, очистка буфера обмена через 30 с
- **Импорт/экспорт**: запароленный ZIP `.nbk` с `data.json`, `media/`, `checksum.sha256`
- **Виджеты**: быстрая заметка, чек-лист (базовая заготовка)
- **Тема**: авто / светлая / тёмная, динамические цвета Android 12+

## Сборка

1. Откройте проект в Android Studio Hedgehog или новее
2. Убедитесь, что установлен Android SDK 34
3. Синхронизируйте Gradle и соберите:

```bash
./gradlew assembleDebug
```

## RuStore

Приложение не использует Google Play Services. Для публикации в RuStore:

- Подпишите release-сборку своим ключом
- Подготовьте скриншоты и описание на русском языке
- Укажите разрешения: камера, уведомления, биометрия, микрофон (голосовой ввод в виджете)

## Безопасность Сейфа

1. Мастер-пароль → PBKDF2 (100 000 итераций) → ключ SQLCipher
2. Соль и хеш фразы восстановления — в EncryptedSharedPreferences
3. После успешного входа ключ оборачивается через AndroidKeyStore (биометрия)
4. Ключ биометрии инвалидируется при смене отпечатков и после перезагрузки устройства
