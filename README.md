## Цена места

Веб-приложение для анализа коммерческой локации по адресу. Показывает точку на карте OpenStreetMap и демонстрационные метрики: пешеходный трафик, арендную ставку, конкурентов и кадастровую стоимость.

### Стек

- HTML + CSS + JavaScript (без фреймворков и сборщиков)
- [Leaflet.js](https://leafletjs.com/) — карта OpenStreetMap
- [Nominatim](https://nominatim.org/) — бесплатный геокодер

### Структура

```
cena-mesta/
├── index.html   # страница приложения
├── style.css    # тёмная адаптивная тема
└── script.js    # карта, геокодер, заглушки аналитики
```

### Как запустить

**Вариант 1 — открыть файл напрямую**

1. Перейдите в папку `cena-mesta/`
2. Откройте `index.html` в браузере (двойной клик или перетаскивание в окно браузера)

> При открытии через `file://` геокодер может не отвечать из‑за ограничений браузера (CORS). Если запросы не проходят — используйте локальный сервер (вариант 2).

**Вариант 2 — локальный HTTP-сервер (рекомендуется)**

```bash
cd cena-mesta
python3 -m http.server 8080
```

Откройте в браузере: [http://localhost:8080](http://localhost:8080)

**Вариант 3 — GitHub Pages**

1. В настройках репозитория: **Settings → Pages**
2. Source: ветка `main`, папка `/cena-mesta`
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`

### Использование

1. Введите адрес в поле сверху (например: `Москва, Тверская улица, 1`)
2. Нажмите **Анализировать** — приложение найдёт координаты и поставит метку на карте
3. Под картой появятся результаты анализа (демонстрационные заглушки)
4. Кнопка **Моё местоположение** центрирует карту на ваших GPS-координатах

### Ограничения

- Данные аналитики — заглушки, реальный сервер не подключён
- Nominatim: не более 1 запроса в секунду (политика использования OSM)
- Для продакшена потребуется собственный бэкенд и реальные источники данных
